# Placeholder map geometry: notice

Generated by `tools/maps/import.ts --placeholder`. Do not edit these files by hand; regenerate them
with `pnpm maps:placeholder` (the same as `pnpm tsx tools/maps/import.ts --placeholder`) and check
them with `pnpm maps:validate`.

## What these files are

`geometry.placeholder.json` holds zone frames and map metadata for the procedural placeholder map:
the world-yard rectangle of every UiMap, its world map, its name, and the Era→Forever coefficients
of the four changed zones. It contains no map art, no terrain and no images.

Frame hash of the 49 QuestieDB frames (docs/MAPS.md §5.6):
`2cb10551b1502b652e4d54922e8b3a1ecb48057fbfb7cf9c77863edd7efea78f`. Content hash of every row, name,
parent and coefficient (docs/MAPS.md §5.3), which the app checks before it uses the file:
`c05a47a276295348a5b40a98dbe13c39ddc6fb4a899c21c821714ebf51c4e6ca`.
