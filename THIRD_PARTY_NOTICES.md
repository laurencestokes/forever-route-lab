  API `license: null`). Questie's unmerged `license` branch (commits `ce65498c`, 2023-02-13, to

- **Owner's posture** (D-016): the owner decided to build, commit and publish the derived dataset

  contributions and, as a posture, to Questie-derived data; it grants no rights over Blizzard
  content (names, text, client-derived values) or other third-party material embedded in that
  data. This is not a legal conclusion.
- **Origins embedded in the data**, as declared upstream (listed per output file in the manifest's
  `origins`, DATA_PROVENANCE §8.2):
  - Blizzard game content: entity names, quest and objective text (`objectivesText`), zone and
    dungeon names.
  - Blizzard client-derived values: AreaID→UiMapID links and the Era→Forever coordinate
    projection, from client DBC exports at builds 1.15.9.69722 and 1.60.1.69893.

  - Quest XP (`{questLevel, baseXp}`): an Era seed; upstream does not state where the values come
    from.
  - **Not included:** QuestieDB's drop-percentage tables, which declare Wowhead- and
    CMaNGOS-generated origins.
- **Files:**
  - `public/data/**`: the generated dataset (`quests.json`, `entities.json`, `items.json`,
    `spawns.json`, `zones.json`, `overlays.json`, `manifest.json`, `NOTICE.md`);

  - `public/maps/placeholder/**`: 49 QuestieDB-derived zone frames plus 12 cited DB2 rows (see

  (and, for the 12 DB2 rows, from `tools/maps/inputs/db2-rows-1.60.1.70009.json`) and are never
  hand-edited. Raw upstream Lua is never committed (D-002).
- **Where the notices live:** `public/data/NOTICE.md` (shipped as `dist/data/NOTICE.md`, which
  the build audit requires), `public/maps/placeholder/NOTICE.md`, `tests/fixtures/data/NOTICE.md`,
  the `_generated` first key of every generated JSON file, the README, and the in-app About dialog.

## Map geometry

- **File:** `public/maps/placeholder/geometry.placeholder.json` with its `NOTICE.md` (D-018).
- **49 zone frames** from QuestieDB `data/Forever/conversion.json`
  (`geometry.transforms[].target_bounds`, Forever DBC target build 1.60.1.69893), marked
  `source: 'questiedb-conversion'`. They are Questie-derived, carry client-derived values, and
  are covered by the Data entry above.
- **12 DB2-only `UiMapAssignment` rows** for 11 UiMaps: Azeroth 947 (two rows, one per
  continent map), Kalimdor 1414, Eastern Kingdoms 1415, 1463, 1464, and the new Forever maps
  Mount Hyjal 2482, Zephras Isle 2521 and 2665, Darkspear Islands 2524, Riverglades 2548 and
  Shen'dralas 2652. They were taken at build **1.60.1.70009** from a CSV fetched as an individual request during research (not scripted crawling)
  (`UiMapAssignment` SHA-256
  `79267e8be8034e47daab14350411b3acc0b1f64e86efc9d821a217497254ca0a`), and are marked
  `source: 'db2-csv'`, each row citing table, build and row ID. They are Blizzard client-derived
  values, committed by owner approval (D-018; cited individual values are allowed, D-022).
- **No map art.** No Blizzard artwork is committed or deployed. Local map sets live in the
  gitignored `local-maps/` folder, outside `public/`. Only a dev/preview plugin serves them, and
  the build audit fails if map-like files reach `dist/` (D-018; [docs/MAPS.md](docs/MAPS.md)).

## Software dependencies

Generated at build time, not maintained here. `tools/build/third-party-notices.ts` writes
`dist/third-party-notices.txt` from installed package metadata. It covers production dependencies
and any development dependency whose code reaches `dist/`. `tools/build/licence-gate.ts` checks
the same set against an SPDX allowlist (MIT, ISC, BSD-2-Clause, BSD-3-Clause, Apache-2.0, 0BSD,
Zlib, CC0-1.0, BlueOak-1.0.0); anything else needs an exceptions entry and a decision
(ARCHITECTURE §16, D-025). The planned dependency set and its declared licences are listed in
ARCHITECTURE §16.
